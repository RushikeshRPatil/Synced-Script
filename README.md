Synced-Script is a web-based Integrated Development Environment (IDE) designed for seamless, real-time collaboration. It empowers development teams to write code, communicate, and brainstorm ideas simultaneously within a single, unified platform.

---

## ✨ Key Features

* **Real-Time Collaborative Editor:** Multiple users can write and edit code in the same file simultaneously, with changes reflected instantly.
* **Integrated Chat Application:** Communicate with your teammates directly within the IDE without switching tabs.
* **Brainstorming Board (TLDR):** A dedicated space to jot down notes, plan tasks, and brainstorm ideas together.
* **Customizable Editor:** Adjust settings like programming language syntax and font styles to suit your preferences.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript
* **Styling:** Tailwind CSS
* **Real-Time Communication:** WebSockets

## ⚙️ Getting Started

Follow these instructions to get a local copy of the project up and running.

### Prerequisites

Make sure you have the following installed on your machine:

* **Node.js:** v17.x or v18.x (or higher)
* **npm** (Node Package Manager) or **yarn**

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/RushikeshRPatil/Synced-Script.git
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd Synced-Script
    ```
3.  **Install the dependencies:**
    ```sh
    npm install
    ```
    or if you use yarn:
    ```sh
    yarn install
    ```
